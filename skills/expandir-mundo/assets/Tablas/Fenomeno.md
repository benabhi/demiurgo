# Tablas: Fenómeno

Ingredientes para fenómenos extraordinarios. Son genéricos para cualquier género: Claude los adapta al mundo (una "lluvia extraña" puede ser de esporas, de cristal o de partículas) y los reconcilia con lo que ya existe. A más peso, más frecuente.

| Peso | Resultado |
|---|---|
| 2 | Niebla, bruma o humo |
| 2 | Lluvia, nieve o granizo extraños |
| 2 | Luz, resplandor o colores imposibles |
| 2 | Sonido, voces o un silencio antinatural |
| 2 | Viento o tormenta que no amaina |
| 2 | Temblores, grietas o tierra que se mueve |
| 2 | Agua que cambia: mareas, ríos o pozos |
| 1 | Sombra u oscuridad |
| 1 | Sueños o visiones compartidas |
| 1 | El tiempo se comporta de forma extraña |
| 1 | Algo que solo se ve de reojo |
| 1 | Una frontera invisible que se nota al cruzarla |
